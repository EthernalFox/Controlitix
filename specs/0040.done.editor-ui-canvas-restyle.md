# 0040: editor-ui — Editor canvas restyle: grid, transformer, snap, overlays, контекстное меню, хоткеи

## Scope

`editor-ui/src/`:

1. Konva canvas: grid background, light/dark адаптация фона.
2. Transformer styling: dashed accent outline, white corner handles.
3. Multi-select bounding box: dashed + soft fill.
4. Snap-lines (1px accent dashed) при drag с включённым Snap.
5. Cursor coordinates overlay (моно-чип сверху-слева).
6. Контекстное меню (ПКМ) — glass-strong popover с keyboard hints.
7. Полный набор keyboard shortcuts (см. таблицу хэндоффа).
8. Banners в Editor mode: save error (footer), connection lost (top).
9. Editor states: empty / default / single-select / multi-select / drag-in-progress / save-error / connection-lost.

Out of scope: изменение модели данных фигур (это 0025); WS-интеграция в editor (editor работает только с REST + autosave); design-tokens (0037).

Зависимости: 0037, 0038, 0039.

## Interface

### Canvas grid

Реализация — CSS-фон на контейнере Konva:

```css
.canvasContainer {
  background-color: var(--canvas-bg);
  background-image:
    linear-gradient(to right,
      color-mix(in srgb, var(--text-muted) 18%, transparent) 1px,
      transparent 1px),
    linear-gradient(to bottom,
      color-mix(in srgb, var(--text-muted) 18%, transparent) 1px,
      transparent 1px);
  background-size: 20px 20px;
}
.canvasContainer.gridOff { background-image: none; }
```

Альтернатива — `Konva.Layer` с `Line`-объектами; от неё **отказываемся** в пользу CSS (быстрее, не ест GPU при панорамировании). При zoom — CSS-фон масштабируется через `background-size: calc(20px * var(--zoom)) ...`.

### Transformer (single-select)

Konva `Transformer` props:
```ts
{
  borderEnabled: true,
  borderStroke: "var(--accent-blue)",  // через DOM-токены не работает в Konva, передаём computed value
  borderStrokeWidth: 2,
  borderDash: [6, 4],
  anchorSize: 8,
  anchorStroke: "var(--accent-blue)",
  anchorStrokeWidth: 1.5,
  anchorFill: "#FFFFFF",
  anchorCornerRadius: 1,
  rotateAnchorOffset: 24,
  enabledAnchors: ["top-left", "top-right", "bottom-left", "bottom-right", "top-center", "middle-right", "bottom-center", "middle-left"],
}
```

Так как Konva не читает CSS-vars — добавить хелпер `useThemeColor(varName)` (читает `getComputedStyle(document.body).getPropertyValue(varName)` + подписан на `data-theme` change через `MutationObserver`).

### Multi-select bounding box

При `selection.ids.length >= 2` — рендерим отдельный `<Rect>` поверх с:
- `stroke: var(--accent-blue)`, `strokeWidth: 1.5`, `dash: [4, 3]`.
- `fill: rgba(34,139,230,0.05)` (или dark-вариант — `rgba(76,154,255,0.08)`).
- Standard Konva bbox по выделенным фигурам (`Konva.Util.haveIntersection` или вручную).

Transformer per-figure скрывается при multi-select (Properties — только общие поля).

### Snap-lines

При `dragging != null && snapEnabled === true`:

1. На каждый `dragmove` — пересчитать кандидаты-линии: фигуры в radius 200px от drag-объекта; для каждой проверить совпадение по X/Y (центры/края).
2. Если совпадение в `±4px` — snap к линии и нарисовать guide:
   ```ts
   <Line
     points={[x1, y1, x2, y2]}
     stroke="var(--accent-blue)"
     strokeWidth={1}
     dash={[4, 4]}
     listening={false}
   />
   ```
3. На `dragend` — стереть guides.

### Cursor coordinates overlay

```tsx
<div className={styles.cursorChip}>
  cursor: <span className="mono">{cursor.x.toFixed(1)}</span>, <span className="mono">{cursor.y.toFixed(1)}</span>
</div>
```

Position: `absolute; top: 8px; left: 8px;` поверх canvas. Стиль — `glass-strong` + `padding: 4px 10px` + `border-radius: 999px` + `font: 11px JetBrains Mono`.

Прячется при `cursor === null` (мышь вне canvas).

### Контекстное меню

Glass-strong popover, рендерится через Mantine `Menu` с custom className (`.editorContextMenu`):

```
Дублировать      ⌘D
Привязать к тегу B
На передний план
На задний план
─────────────────
Удалить (red)    Del
```

Items: padding `7px 10px`, font 12px, radius 6px, hover `var(--glass-bg-soft)`. Шорткаты справа `font-family: var(--font-mono)`, `color: var(--text-muted)`. Раздел разделён `1px solid var(--border-default)` hairline. Delete-item — `color: var(--alarm-crit)`.

Открытие: правый клик по фигуре → `Menu` позиционируется по `event.clientX/Y`, `selection.ids = [clickedFigureId]` если ещё не в выделении.

### Keyboard shortcuts

| Действие | Шорткат | Условие |
|---|---|---|
| Undo | `Cmd/Ctrl+Z` | always |
| Redo | `Cmd/Ctrl+Shift+Z` | always |
| Delete | `Delete` / `Backspace` | `selection.ids.length > 0` |
| Duplicate | `Cmd/Ctrl+D` | `selection.ids.length > 0`, preventDefault |
| Deselect | `Esc` | always |
| Zoom in | `+` или `=` | always |
| Zoom out | `-` | always |
| Fit to screen | `Cmd/Ctrl+0` | always, preventDefault |
| Publish | `Cmd/Ctrl+ArrowUp` | always |
| Bind tag | `B` | `selection.ids.length === 1` |
| Tool: Rect | `R` | always |
| Tool: Circle | `C` | always |
| Tool: Line | `L` | always |
| Tool: Text | `T` | always |

`useEditorShortcuts(editorStore)` хук — `useEffect` с `keydown` listener на `window`, диспатчит actions; не срабатывает, если фокус в `<input>`/`<textarea>`/`contenteditable`.

### Save error banner (footer)

```tsx
{saveStatus === "error" && (
  <div className={styles.saveErrorBanner}>
    <IconAlertTriangle size={14} />
    <span>Не удалось сохранить</span>
    <Button size="xs" variant="ghost" onClick={retry}>Повторить</Button>
  </div>
)}
```

Стиль: `background: rgba(239, 83, 80, 0.1)`, `border: 1px solid var(--alarm-crit)`, `border-radius: 8px`, `padding: 4px 10px`, `font-size: 12px`. Inline в footer слева от Zoom-controls.

### Connection lost banner (top)

```tsx
{connectionStatus === "offline" && (
  <div className={styles.connectionLostBanner}>
    <IconBolt size={14} />
    <span>Соединение потеряно · автосохранение приостановлено</span>
  </div>
)}
```

Position: top of editor area (между Header и Main). `background: rgba(255, 167, 38, 0.1)`, `border-bottom: 1px solid var(--alarm-warn)`, `padding: 6px 16px`, `font-size: 12px`. Появляется при `connectionStatus === "offline"`.

Логика `connectionStatus`: editor не на realtime, поэтому это просто детектор online/offline через `window.navigator.onLine` + listener `online`/`offline` events. На `online` баннер исчезает с задержкой 500ms.

### Empty state (нет фигур)

Centered prompt:

```tsx
<div className={styles.emptyState}>
  <div className={styles.dashedSquare}>
    <IconPlus size={28} color="var(--accent-blue)" />
  </div>
  <p className={styles.title}>Перетащите фигуру из палитры</p>
  <div className={styles.hints}>
    <kbd>R</kbd> Rect
    <kbd>C</kbd> Circle
    <kbd>L</kbd> Line
    <kbd>T</kbd> Text
  </div>
</div>
```

`.dashedSquare`: 64×64, `border: 2px dashed var(--border-default)`, `border-radius: 8px`. `.hints kbd`: моно-чип `padding: 2px 6px`, `border: 1px solid var(--border-default)`, `border-radius: 4px`, `font: 11px JetBrains Mono`.

## Constraints

- Konva-объекты не читают CSS-vars напрямую. Использовать helper `useThemeColor("--accent-blue")` который пересчитывает значения при смене `data-theme` (через `MutationObserver` на `document.body`).
- Grid через CSS — НЕ через Konva-линии (производительность).
- Snap-логика в виде pure-функций (`computeSnapTargets(figures, draggingId, threshold) → Point[]`). Юнит-тестируется отдельно.
- `useEditorShortcuts` не подписывается на keydown пока активен `<input>`/`<textarea>`. Иначе при наборе `R` в TextField появится новый Rect — bug.
- `Esc` снимает выделение, **но не закрывает** Modal (Mantine сам обрабатывает). Порядок: если открыт Modal/Drawer/Popover → Esc их закрывает (Mantine), иначе наш hook ловит и снимает selection.
- `Cmd/Ctrl+D` — `event.preventDefault()` обязательно (иначе браузер откроет «Bookmark this page»).
- `Cmd/Ctrl+0` — `event.preventDefault()` обязательно (иначе браузер сбросит zoom).
- Контекстное меню рендерится через portal (Mantine Menu делает по умолчанию); закрывается на Esc, click outside, click на item.
- Banner save-error и connection-lost — отдельные компоненты, не вшитые в footer/header. Подписаны на store-slice.
- AlarmBadge / glass-классы из 0039 / 0038 — переиспользуем, не дублируем стили.
- Shape preview при drag из палитры — Mantine не подходит (HTML-DnD vs Konva). Используем custom drag-image: на `dragstart` от палитры запоминаем тип; на `mouseup` над canvas — создаём Konva-объект в курсорной точке (есть в 0011, не трогаем).
- Cursor overlay обновляется не чаще 30 Hz (throttle) — не убивает FPS при движении мыши.

## Verify

- `npm run build && npm run lint` — без ошибок.
- Открыть пустую мнемосхему → виден empty state с подсказкой и хоткеями.
- Перетащить Rect из палитры → empty state исчез, фигура отрисована, grid виден на фоне.
- Кликнуть фигуру → transformer dashed accent + 4 corner handles.
- Shift+click вторую → multi-select bounding box (dashed + soft fill); Properties tab показывает только общие поля.
- При Drag фигуры: тень под фигурой; при включённом Snap — синие dashed snap-линии при совпадении по краю/центру другой фигуры.
- Cursor coords overlay сверху-слева, обновляется при движении мыши; скрывается при `mouseleave` canvas.
- Правый клик по фигуре → glass-strong popover с 5 пунктами + шорткатами; click outside / Esc — закрывает.
- Хоткеи:
  - `Cmd+Z` undo, `Cmd+Shift+Z` redo.
  - `Del` удаляет выделенные.
  - `Cmd+D` дублирует (без открытия bookmark dialog).
  - `Esc` снимает выделение (но не ломает открытый Drawer/Modal).
  - `+/-` zoom; `Cmd+0` fit.
  - `B` при single-select открывает Data Binding tab.
  - `R/C/L/T` — переключают активный shape-tool в палитре.
- Хоткеи **не** срабатывают при фокусе в `<TextInput>` (попробовать ввести `R` в Properties - не создаёт Rect).
- Save error baner появляется при `saveStatus === "error"`; «Повторить» вызывает retry.
- Отключить интернет в DevTools (offline) → top-banner «Соединение потеряно» появляется через ~1s; включить — исчезает.
- Переключение темы во время editor сессии — grid, transformer, snap-guides перекрашиваются (через `useThemeColor` + MutationObserver).
- 200 фигур, drag одной — 60 fps; snap-вычисления не вызывают jank.
