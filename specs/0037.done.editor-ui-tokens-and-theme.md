# 0037: editor-ui — Foundations: токены, шрифты, Mantine theme, Design-Decisions

## Scope

Foundations-слой для liquid-glass дизайна editor-ui:

1. CSS-переменные дизайн-токенов (light/dark) — `editor-ui/src/app/index.css`.
2. Подключение шрифтов **Inter** и **JetBrains Mono**.
3. Полная пересборка Mantine `createTheme()`: `primaryColor`, custom palettes (включая alarms), spacing, fontSizes, defaultRadius, typography.
4. `ThemeProvider` синхронизирует Mantine `colorScheme` с `data-theme` атрибутом `<body>` (CSS-переменные привязаны к атрибуту).
5. Документация: `docs/06_Дизайн/Design-Decisions.md` — фиксация сознательного отклонения от дизайн-брифа (glass-эффект на chrome).

Out of scope: glass-классы и применение токенов в компонентах/AppShell — это 0038. Без 0037 ничего другого не запустится (Foundation gate).

### Mantine palette generation

Для каждой semantic-палитры (`deepBlue`, `alarmOk`, …) сгенерировать 10 оттенков, центр (`[6]`) = базовый hex. Алгоритм — по существующему паттерну `LIGHT_PALETTE` (см. `constants.ts`): шаги светлее/темнее по HSL. Допустимо использовать Mantine helper `generateColors` из `@mantine/colors-generator` (если он не утяжеляет bundle) или статически задать массивы. Default — статически (предсказуемо).

Пример для `alarmCrit` (центр `#EF5350`):
```ts
alarmCrit: [
  "#FFEBEE", "#FFCDD2", "#EF9A9A", "#E57373", "#EF5350",
  "#EF5350", // 5 — уравниваем с base, чтобы [5] и [6] совпадали
  "#EF5350", // 6 — base
  "#E53935", "#D32F2F", "#C62828",
],
```
(Mantine на `[6]` ставит базовый — это и нужно для `color="alarmCrit"`.)

### `Design-Decisions.md` — структура

```md
# Design Decisions — Controlitix

Лог архитектурных дизайн-решений, отклонений от брифа и контракта дизайн-системы.

## DD-001 (2026-04-26): Liquid glass на chrome editor-ui

Решение: применить эффект liquid glass (backdrop-filter blur, полупрозрачные фоны, soft shadows) на chrome-слот лейаута (Header, Panel, Aside, Footer, Modal, Popover, Dropdown).

Контекст: бриф `docs/06_Дизайн/Design-Brief-editor-ui.md` § 10 запрещает glassmorphism. По запросу заказчика и подтверждённому хэндоффу `design_handoff_editor_ui/` применяем glass только на chrome — карточки данных, строки таблиц, превью значений тегов остаются плоскими.

Последствия:
- Контраст текста проверяется отдельно: glass-фон на ярком backdrop требует усиленного contrast-ratio (≥ 4.5:1).
- Mobile/low-end machines: проверить FPS canvas-сцены при включённом backdrop-filter; если просадки — отключать glass на `prefers-reduced-transparency: reduce`.
- Старые браузеры без `backdrop-filter` (Safari < 14) — fallback на solid `--bg-surface`.
```

## Constraints

- Точные значения токенов — копировать из HTML-референса 1-в-1 (включая `rgba` с floats до 2 знаков). Любые отклонения — исключительно через `Design-Decisions.md`.
- Не удалять существующие палитры `primary`/`secondary`/`light`/`dark` из `constants.ts` — другие виджеты ещё их используют. Удаление — после миграции в 0039.
- `defaultColorScheme = "light"` — соответствует Design-System.md. Существующие пользователи с сохранённым в `localStorage` `dark` остаются на dark.
- Шрифты подключаются ровно один раз в `index.html`. Запрещено импортировать через `@import url(...)` в CSS (slow first paint).
- `data-theme` — единственный источник CSS-переменных. Mantine `colorScheme` синхронизируется с ним через `useEffect`. Не дублировать токены в Mantine inline-styles.
- `font-family` базовых элементов задаётся через Mantine `theme.fontFamily`; `font-mono` — через классы/Mantine `<Text ff="monospace">` и `var(--font-mono)`. Никаких inline `font-family: 'JetBrains Mono'` в JSX.
- `Design-Decisions.md` ссылается на конкретные файлы и строки HTML-референса — это даёт verifiability через год.
- Bundle: при использовании `@mantine/colors-generator` проверить, что он tree-shakeable. Если нет — статический массив.
