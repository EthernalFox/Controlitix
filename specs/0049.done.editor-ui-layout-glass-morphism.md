# 0049: editor-ui — Layout & Glass Morphism (токен-driven)

## Scope

`editor-ui/src/shared/ui/Layout/`

## Context

Решение DD-001 (2026-04-26) утверждает liquid glass для chrome-элементов editor-ui: Header, Panel, Aside, Footer, а также Modal, Popover, Dropdown. Текущая реализация либо использует хардкодированные значения, либо ссылается на старые `var(--glass-*)` токены (устаревшее пространство имён из spec 0047). Компонентные CSS-модули Layout-слоя нужно привести к `--ctrx-glass-*` и `--ctrx-*` токенам из нового resolver'а.

Зависимости: **выполнять после** спеки 0047 и 0048.

Дополнительно: добавить `@supports`-fallback для `backdrop-filter` и `@media (prefers-reduced-transparency: reduce)`.

## Files

- `editor-ui/src/shared/ui/Layout/Header/Header.module.css` — glass morphism через `--ctrx-glass-*`
- `editor-ui/src/shared/ui/Layout/Panel/Panel.module.css` — аналогично
- `editor-ui/src/shared/ui/Layout/Aside/Aside.module.css` — аналогично
- `editor-ui/src/shared/ui/Layout/Footer/Footer.module.css` — аналогично
- `editor-ui/src/shared/ui/Layout/Layout.module.css` (или `Layout.tsx`) — размерные токены (`--ctrx-header-h`, `--ctrx-panel-w`, `--ctrx-aside-w`, `--ctrx-footer-h`)
- `editor-ui/src/shared/ui/components/Modal/Modal.module.css` — glass overlay, тень
- `editor-ui/src/shared/ui/components/Popover/Popover.module.css` — glass surface

## Interface

### Паттерн glass chrome (применять к Header, Panel, Aside, Footer)

```css
.root {
  background: var(--ctrx-glass-bg);
  backdrop-filter: var(--ctrx-glass-blur);
  -webkit-backdrop-filter: var(--ctrx-glass-blur);
  border-color: var(--ctrx-glass-border);
  box-shadow: var(--ctrx-glass-shadow);
}

/* Highlight-градиент поверх (псевдоэлемент) */
.root::before {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--ctrx-glass-highlight);
  pointer-events: none;
  border-radius: inherit;
}

/* Fallback: нет поддержки backdrop-filter */
@supports not (backdrop-filter: blur(1px)) {
  .root {
    background: var(--ctrx-bg-surface);
    backdrop-filter: none;
  }
}

/* Fallback: пользователь предпочитает уменьшенную прозрачность */
@media (prefers-reduced-transparency: reduce) {
  .root {
    background: var(--ctrx-bg-surface);
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
  }
}
```

### Размерные токены в AppShell

AppShell-пропсы `header.height`, `navbar.width`, `aside.width`, `footer.height` должны ссылаться на CSS-переменные через `rem()` утилиту Mantine или прямое числовое значение. В Layout.tsx заменить хардкоды:

```tsx
// До:
<AppShell header={{ height: 56 }} navbar={{ width: 240 }}>

// После: читать CSS vars через style prop или оставить числа, но
// согласовать с --ctrx-header-h (56px), --ctrx-panel-w (240px)
// Mantine не читает CSS vars из AppShell props — оставить числа,
// но добавить комментарий-ссылку на токены для документации.
```

## Constraints

- Не хардкодить rgba(), hex или blur-значения в CSS-модулях — только `var(--ctrx-*)`.
- `backdrop-filter` требует `position: relative` + `overflow: hidden` на родителе — проверить что это соблюдено.
- `z-index` стекинг: Header > Panel/Aside > Footer > контент — не менять без явного указания в спеке.
- `border-radius` chrome-элементов — `0` (они прилегают к краям экрана); glassmorphism только на `Modal`, `Popover`, `Menu` — у них `border-radius: var(--mantine-radius-md)`.
- Не использовать `filter: blur()` вместо `backdrop-filter` — `filter` влияет на содержимое элемента, `backdrop-filter` — на то, что за ним.
- FPS оптимизация: добавить `will-change: backdrop-filter` только к Header и Panel (наиболее заметные). Не ставить на все элементы (memory cost).
- Alarm-цвета в Layout не используются — не добавлять.

## Verify

```bash
cd editor-ui
npx tsc --noEmit
grep -r "var(--glass-" src/shared/ui/Layout/    # 0 совпадений (старое пространство имён)
grep -r "rgba(" src/shared/ui/Layout/           # 0 совпадений
grep -r "blur(" src/shared/ui/Layout/           # 0 совпадений (все через --ctrx-glass-blur)
```

Визуальная проверка:
1. Light mode: Header и Panel имеют молочный полупрозрачный фон с тенью (glass).
2. Dark mode: Header и Panel — тёмно-синий полупрозрачный фон.
3. Переключение темы → glass плавно меняет цвет.
4. В браузере без поддержки `backdrop-filter` (Firefox с отключённой настройкой) — сплошной `--ctrx-bg-surface`.
5. Профиль FPS в DevTools при 500 фигурах на canvas — не ниже 55 fps.
