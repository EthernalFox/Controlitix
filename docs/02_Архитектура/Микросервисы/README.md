# 2.2 Микросервисы и границы

Список микросервисов по диаграмме (`Controlitix.drawio`) и их зоны ответственности. Детализация API — в `04_API/`.

- 2.2.1 ms-editor — конфигурация объектов, устройств, тегов, мнемосхем и фигур, публикация изменений.
- 2.2.2 ms-poll — опрос устройств (Modbus TCP/RTU, SNMP), публикация значений.
- 2.2.3 ms-viewer — единый backend просмотра: realtime, кэш последних значений, история, тренды, тревоги и Telegram-уведомления.
- 2.2.4 ms-auth — аутентификация/авторизация, токены, роли.

Фронтенд‑модули
- 2.2.5 editor-ui — единый UI редактора мнемосхем и конфигурации устройств.
- 2.2.6 viewer-ui — UI просмотрщика мнемосхем, тревог и трендов.
