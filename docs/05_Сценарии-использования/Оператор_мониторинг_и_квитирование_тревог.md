#+ Оператор: мониторинг и квитирование тревог

Как оператор, я хочу видеть активные тревоги и квитировать их, чтобы фиксировать реакцию на события.

Предусловия
- Настроены уставки (`tags.tag_setpoints`), модуль тревог `ms-viewer` активен.

Поток
1) Получить уведомление (Viewer/Telegram).
2) Открыть список активных тревог (реaltime).
3) Квитировать тревогу с комментарием (REST TBA) и проверить, что состояние изменилось.

Acceptance Criteria
- Для каждой тревоги видны состояние, приоритет, время, источник (tag).
- Квитирование фиксируется в аудите; повторные уведомления подавляются.

Связанные сущности и API
- Таблицы: `tags.tag_setpoints` (+ аудит TBA).
- Потоки: `alarms.events`.
