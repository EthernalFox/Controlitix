# 0041: editor-ui — Restyle экранов (Login, Devices table, Drawer-формы, system 4xx, empty/loading)

## Scope

`editor-ui/src/pages/` и связанные `widgets/`:

1. `LoginPage` — full-stage с pastel-orbs background + glass card 380px.
2. Devices table — glass-card обёртка + uppercase header + status-dot первая ячейка + toolbar.
3. Аналогично — Tags table, Diagrams list (унификация табличного паттерна).
4. `TagDrawer` (расширенная форма): per-protocol address, scaling 4-grid, setpoints 4-grid c alarm-цветами.
5. `DeviceDrawer` (per-protocol settings) — апдейт стиля.
6. `DiagramFormModal` — апдейт.
7. System screens: `403 / 404 / 500 / Session Expired` — gradient-text для кода, glass-card.
8. Empty / Loading skeletons для всех списков.

Out of scope: бизнес-логика форм (валидация уже есть в 0007); routing (есть); editor (0040).

Зависимости: 0037, 0038, 0039.

```tsx
<PageToolbar

<Card variant="glass" className={styles.tableCard} p={0}>
  <Table>
    <Table.Thead className={styles.thead}>
      <Table.Tr>
```

Стиль:

### TagDrawer (расширенная форма)

Glass-strong panel 380px, `<Drawer position="right">`. Содержимое:

**Секция «Основное»:**
- `<TextInput label="Имя тега" required />`.
- `<Select label="Устройство" data={...} />`.
- `<Select label="Тип данных" data={dataTypes} />`.
- `<Select label="Единица" data={units} clearable />`.

**Секция «Адрес»** (per-protocol — рендерится по типу выбранного устройства):

Modbus (rtu/tcp):
- `<Select label="Тип регистра" data={["holding","input","coil","discrete"]} />`.
- `<NumberInput label="Address" mono min={0} max={65535} />`.

SNMP (v1/v2c/v3):
- `<TextInput label="OID" mono placeholder="1.3.6.1..." />`.

**Секция «Scaling»** (4 моно-инпута, 2×2 grid):
```tsx
<SimpleGrid cols={2} spacing="sm">
  <NumberInput label="raw_min" mono />
  <NumberInput label="raw_max" mono />
  <NumberInput label="eng_min" mono />
  <NumberInput label="eng_max" mono />
</SimpleGrid>
```
Каждый — `font-family: var(--font-mono)` через `mono` prop из 0039.

**Секция «Setpoints»** (4 моно-инпута, 1×4 grid):
```tsx
<Group grow>
  <NumberInput label="LoLo" mono className={styles.setpointLolo} />
  <NumberInput label="Lo"   mono className={styles.setpointLo} />
  <NumberInput label="Hi"   mono className={styles.setpointHi} />
  <NumberInput label="HiHi" mono className={styles.setpointHihi} />
</Group>
```
CSS:
```css

.setpointLo   { --setpoint-color: var(--alarm-warn); }
```

**Footer drawer:**
- `<Button variant="ghost" onClick={onCancel}>Отмена</Button>`.
- `<Button variant="primary" onClick={onSave}>Сохранить</Button>`.

### DeviceDrawer (per-protocol settings)

Та же структура; per-protocol fields для:
- `modbus_rtu`: serial_port (TextInput), baud_rate (Select из 8 значений), data_bits (Select 7/8), parity (Select), stop_bits (Select 1/2), slave_id (NumberInput 1..247 mono), timeout_ms (NumberInput 100..30000 mono).
- `modbus_tcp`: host (TextInput), port (NumberInput 1..65535 mono), slave_id, timeout_ms.
- `snmp_v1`/`v2c`: host, port, community, timeout_ms, retry_count.
- `snmp_v3`: host, port, security_name, security_level (Select), auth_protocol (Select), auth_password, priv_protocol, priv_password, timeout_ms, retry_count.

Условные показ полей — через `if (level === 'authNoPriv') ...` (см. контракт 0007).


`SkeletonCard`: `width: 100%; height: 120px; border-radius: 14px; background: linear-gradient(90deg, var(--glass-bg-soft), var(--glass-bg-strong), var(--glass-bg-soft)); background-size: 200% 100%; animation: shimmer 1.4s linear infinite`.

## Constraints

- LoginPage и SystemErrorPage **не используют** AppShell-обёртку из 0038. Они монтируются на уровне Router как отдельные top-level routes; `AmbientOrbs` рендерится внутри страницы (своя инстанция).
- `gradient-text` в SystemErrorPage — через `background-clip: text` + `color: transparent`. Fallback (старые браузеры) — solid цвет первого stop’а.
- Setpoint-цветные границы — **не** заменяют валидацию. Mantine error-state (`error` prop) добавляется поверх (красный glow) для невалидных значений.
- Per-protocol поля в DeviceDrawer/TagDrawer — динамическая прорисовка через switch по `device.type_name` (или `protocol`). Не дублировать формы статически.
- Skeleton — отдельный компонент, **не** Mantine `Skeleton` (тот не даёт нужный shimmer). Если Mantine `<Skeleton>` визуально подходит — допустимо переиспользовать с custom CSS.
- `EmptyState` — generic, переиспользуется на ObjectsPage / DevicesPage / TagsPage / DiagramsPage. Не делать per-page копии.
- Все таблицы — Mantine `Table` (через фасад). Не вводить новый табличный компонент.
- TagDrawer setpoints — единственное место с цветными границами per-set; в 0033 (alarms) визуал для значений тегов уже использует `AlarmBadge`, не повторять.
- Хэндофф предлагает 4 system-screens — все обязательные. `session-expired` — только для будущей auth-системы (после 0027 для editor); сейчас рендерим контент, но routing к нему — заглушка.
