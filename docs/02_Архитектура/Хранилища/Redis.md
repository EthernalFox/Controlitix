# Redis

Назначение
- Кэш конфигураций (объекты, схемы, привязки тегов) для ускорения чтения.
- Краткоживущие состояния опроса и блокировки/кворумы (если потребуются).
- Pub/Sub для Realtime (опционально, в дополнение или вместо Kafka для локального обновления Viewer).

Ключевые моменты
- Сроки жизни ключей (TTL) для кэша конфигов.
- Namespaces по сервисам: `ms-editor:*`, `ms-viewer:*`, `ms-poll:*`.
- Лимиты памяти, eviction policy.
