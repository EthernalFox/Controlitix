# 0047: editor-ui — Token System v2 (Mantine 8 cssVariablesResolver)

## Scope

`editor-ui/src/shared/libs/theme/`

## Context

Текущий `tokens.css` хранит семантические CSS-переменные в `[data-theme]`-селекторах, дублируя значения из `constants.ts`. Это два источника истины, и они не используют Mantine 8 `cssVariablesResolver` — нативный механизм генерации переменных из темы.

**Принцип переработки (выровнен по философии Mantine 8):**

- `--ctrx-*` токены создаём **только для того, чего Mantine не покрывает**: alarm-цвета, glass morphism, canvas, ambient orbs, layout-размеры.
- Для поверхностей, текста, границ и акцентов — используем `var(--mantine-color-*)` напрямую; Mantine автоматически переключает их при смене схемы.
- Alarm-цвета дублируются в `theme.other` (типизированный JS-доступ) и в `variables`-блоке resolver'а (CSS-доступ из модулей).
- Убираем хак переопределения `--mantine-color-deepBlue-N` в dark-блоке. Единая палитра `deepBlue` для обеих схем — Mantine обеспечивает достаточный контраст через variant/shade-логику компонентов.

Документация: `docs/06_Дизайн/Tokens.md`, `docs/06_Дизайн/Design-System.md`.

## Files

- `editor-ui/src/shared/libs/theme/constants.ts` — заменить `LIGHT_PALETTE` + `DARK_PALETTE` на единый `THEME_PALETTE`
- `editor-ui/src/shared/libs/theme/theme.ts` — добавить `theme.other`, добавить `cssVariablesResolver`, убрать `themeOverrides`
- `editor-ui/src/shared/libs/theme/tokens.css` — очистить; оставить только комментарий-ссылку
- `editor-ui/src/shared/libs/theme/index.ts` — добавить экспорт `cssVariablesResolver`

## Constraints

- Alarm-токены в `variables`-блоке — значение берётся из `ALARM_COLORS`, не хардкодится.
- `LIGHT_PALETTE` и `DARK_PALETTE` удалить; убедиться что ни один файл их не импортирует (`grep -r "LIGHT_PALETTE\|DARK_PALETTE" src/`).
- Не переопределять `--mantine-color-*` переменные в `light`/`dark` блоках — это хрупкий недокументированный API.
- `GRAY_LIGHT` и `GRAY_DARK` массивы сохранить в `THEME_PALETTE` под ключами `light` и `dark` — они нужны Mantine для правильного рендера AppShell в dark mode.
- Не добавлять `--ctrx-bg-*`/`--ctrx-text-*`/`--ctrx-border-*` — они удалены намеренно.
