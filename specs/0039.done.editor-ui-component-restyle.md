# 0039: editor-ui — Restyle базовых компонентов фасада (Button/Input/Tabs/Switch/Modal/Card/Badge/TagSelect)

## Scope

`editor-ui/src/shared/ui/components/` и (где нужно) `widgets/`:

1. `Button` — 4 варианта на glass (`primary`/`secondary`/`danger`/`ghost`).
2. `TextInput`, `NumberInput`, `PasswordInput`, `Textarea` — единый glass-strong inset стиль; модификатор `mono` для моноширинных полей.
3. `Tabs` — pill-сегмент.
4. `Switch` — 32×18 track, on-gradient.
5. `Modal`, `Drawer`, `Popover`, `Menu` — glass-strong с radius 14px.
6. `Card` — flat (data) и glass-flat (chrome) варианты.
7. `Badge` + новый компонент `AlarmBadge` (8 quality-состояний с формой иконки).
8. `TagSelect` — кастомный поверх Mantine `Select` (поиск + unit-suffix + alarm-цвет).
9. `Notification` — glass-strong для тостов (Save / Save error / Network).

Out of scope: применение этих компонентов в pages/widgets — это идёт в 0040 и 0041; редактор-canvas — 0040; экраны — 0041.

Зависимости: 0037, 0038.

## Context

- Хэндофф [README.md](../design_handoff_editor_ui/README.md) § «Components» — спецификация всех вариантов.

## Interface

### `Button`

```tsx
<Button variant="primary" | "secondary" | "danger" | "ghost" size="sm" | "md">…</Button>
```

Маппинг → Mantine + custom classes:

| Variant | Mantine props | CSS class |
|---|---|---|
| `primary`   | `color="deepBlue"`, `variant="filled"`   | `.btnPrimary`   |
| `secondary` | `color="deepBlue"`, `variant="outline"`  | `.btnSecondary` |
| `danger`    | `color="alarmCrit"`, `variant="filled"`  | `.btnDanger`    |
| `ghost`     | `color="deepBlue"`, `variant="subtle"`   | `.btnGhost`     |

CSS — точные значения из HTML-референса (`.btn-primary`, etc.). Все варианты — на `backdrop-filter: blur(20px)` и полупрозрачном фоне; padding `6px 14px` / 13px font-weight 500. Размер `sm`: `4px 10px` / 12px. Icon-only (`btn-icon`): 30×30 квадрат.

Focus-стили: `box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent-blue) 18%, transparent)`.

### `TextInput` family

Высота 30px (Mantine `size="sm"`).
- `background: var(--glass-bg-strong)`.
- `border: 1px solid var(--glass-border-inner)`.
- `border-radius: 8px`.
- Focus: `border-color: var(--accent-blue)` + `box-shadow: 0 0 0 3px color-mix(in srgb, var(--accent-blue) 18%, transparent)`.
- Error: то же, через `var(--alarm-crit)`.

Prop `mono?: boolean` → `font-family: var(--font-mono)` для number/address/identifier-полей.

### `Tabs` (pill variant)

```css
.tabsList {
  background: var(--glass-bg-soft);
  padding: 4px;
  border: 1px solid var(--glass-border-inner);
  border-radius: 10px;
  display: inline-flex;

}
.tab {
  padding: 4px 12px;
  border-radius: 8px;
  font-size: 12px;
  font-weight: 500;

}
.tabActive {
  background: var(--bg-surface);

  box-shadow: 0 1px 2px rgba(0,0,0,0.06);
}
[data-theme="dark"] .tabActive { background: rgba(76,154,255,0.18); }
```

### `Switch`

Track 32×18 / radius 999px / off `var(--glass-bg-soft)`. On — `linear-gradient(180deg, #3A9BEE, #228BE6)` (light) / `linear-gradient(180deg, #5DA8FF, #4C9AFF)` (dark). Knob 12×12 / `background: white` / `box-shadow: 0 1px 2px rgba(0,0,0,0.2)`. Transition `0.2s`.

### `Modal` / `Drawer` / `Popover` / `Menu`

Все — `glass-strong` + `border-radius: 14px` + `padding: 18px` (Modal) / `padding: 7px 10px` per-item (Menu).

Modal backdrop: `rgba(0,0,0,0.06)` + `backdrop-filter: blur(2px)`.

3 состояния публикации (используется в `widgets/EditorToolbar` Publish-flow):
- `saving` — Loader (Mantine) внутри Modal-card.
- `published` — `Circle` 56×56 с `var(--alarm-ok)` фоном + `Check` icon.
- `error` — `Circle` 56×56 с `var(--alarm-crit)` фоном + `!` icon, retry-button.

### `Card`

```tsx
<Card variant="flat" | "glass">…</Card>
```

`flat` (default): `background: var(--bg-surface)` + `border: 1px solid var(--border-default)` + `border-radius: 4px` + `padding: 18px`.
`glass`: класс `.glass` (из 0038) + `border-radius: 14px` + `padding: 18px`.

Использование:
- `flat` — DiagramCard, ObjectCard, строки таблиц, превью в drawer.
- `glass` — карточки на dashboard/system screens.

### `AlarmBadge`

```tsx
<AlarmBadge state="ok" | "warn" | "crit" | "uncertain" | "bad" | "comm" | "offline" | "ack" />
```

Внешний вид:
- `font-size: 11px`, `font-weight: 600`, `font-family: var(--font-mono)`.
- `padding: 3px 8px`, `border-radius: 999px`.
- `background: color-mix(in srgb, var(--alarm-{state}) 15%, transparent)`.
- `color: var(--alarm-{state})`.
- `border: 1px solid var(--alarm-{state})`.

Иконка слева (8×8), форма зависит от state — обязательно (цвет — не единственный носитель):

| state | shape | label-default |
|---|---|---|
| `ok` | заполненный круг | OK |
| `warn` | треугольник | HI / LO |
| `crit` | ромб | HI HI / LO LO |
| `uncertain` | полая окружность | UNC |
| `bad` | штриховка | BAD |
| `comm` | разорванная окружность | COMM |
| `offline` | затемнённый квадрат | OFFLINE |
| `ack` | круг с галочкой | ACK |

Пропс `label?: string` — переопределение текста бейджа (default = таблица выше).

Пропс `blink?: boolean` — анимация opacity 1.0 ↔ 0.4 за 800ms (только для `crit` и `warn` неквитированных). Реализуется как CSS `@keyframes blink-alarm`.

### `TagSelect`

Поверх Mantine `Combobox` или `Select` с поиском.

```tsx
<TagSelect
  value={tagId}
  onChange={(tagId) => ...}
  options={[{ id, name, deviceName, unit, quality }]}
  placeholder="Выберите тег"
/>
```

Item:
- 6px × 8px padding, radius 6px.
- Активный: `background: rgba(34,139,230,0.12)` + `border: 1px solid var(--accent-blue)`.
- Слева — `name` (Inter 13px) + ниже `deviceName` (Inter 11px muted).
- Справа — `unit` (моно, цвет = alarm-цвет state, иначе muted).

Search-input — тот же `TextInput` (sm + mono для адресов? — нет, имя тега может быть произвольным).

### `Notification` (toasts)

Глобальные styles (через `theme.components.Notifications.styles`):
- `glass-strong` + radius 14 + box-shadow.
- Цветовая граница слева (`border-left: 3px solid var(--alarm-{state})`):
  - `success` → `--alarm-ok`.
  - `warning` → `--alarm-warn`.
  - `error` → `--alarm-crit`.
  - `info` → `--accent-blue`.

## Constraints

- Не дублировать стили: общая логика glass-фона — через CSS variables, а не повторять `rgba`-значения.
- Все custom variants Mantine принимают через `factory` API + `vanilla-extract`-альтернатива не вводится. Простой путь — `theme.components.{Component}.classNames` + `Component.module.css`.
- `Button` — единственный вариант custom-API. `variant="primary"` НЕ существует в Mantine из коробки; в фасаде делаем mapping → `color="deepBlue", variant="filled"` + override classNames.
- Glass-фон `Modal` НЕ дублирует backdrop из 0038 на самом ламине — только на card.
- `AlarmBadge` без `tag_id` (только визуал); фактическая привязка к tag-state — на стороне виджетов (data binding в editor; `viewer-ui` — отдельно).
- `TagSelect` поиск — клиентская фильтрация по уже загруженному списку. Если список тегов > 100 — debounced серверный поиск через `GET /api/tags?search=` (контракт уже есть в ms-editor). Решение — отдельный пропс `mode="local" | "remote"`.
- Все компоненты — TypeScript strict; без `any`.
- `Notification` — переписывает глобальные styles, проверить, что текущие toasts (если есть) не сломаются.
- `Drawer`: glass только на content-pane, dimmed-overlay сохраняется (Mantine default).
- Анимация blink — отключается на `prefers-reduced-motion: reduce`.
- Все CSS-модули используют `[data-theme="dark"]` суффикс для dark-overrides, а не `:global(.dark-mode)`.
