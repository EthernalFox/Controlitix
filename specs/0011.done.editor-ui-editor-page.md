# 0011: editor-ui — Страница редактора мнемосхемы

## Scope

`editor-ui` — `pages/EditorPage`, `features/editor`, `entities/figures`, `widgets/Editor*`, `widgets/ShapePalette`, `widgets/LayerList`, `widgets/PropertiesPanel`, `shared/ui/components/`.

## Context

Редактор мнемосхемы — ключевой экран `editor-ui` (IA п.11). Инженер создаёт и редактирует мнемосхему на бесконечном холсте Konva, размещает графические примитивы внутри фрейма экрана, настраивает свойства фигур и привязывает теги.

Зависимости:
- **0008** — маршрутизация, API-клиент, фасадные компоненты (ActionIcon, Tooltip, Divider, ScrollArea, Skeleton).
- **0009** — `entities/diagrams`, навигация из `DiagramCard` на `/objects/:objectId/diagrams/:diagramId/edit`.
- `docs/06_Дизайн/Design-System.md` — editor mode layout: Header + Panel + Main + Aside + Footer.
- `docs/06_Дизайн/Figure-Types.md` — типы фигур и их параметры.
- `docs/04_API/ms-editor.md` — API мнемосхем и фигур.

### Текущее состояние кода

Существуют заглушки: `pages/DrawPage`, `widgets/Draw*`, `features/Draw/Canvas/DrawCanvas.tsx` (placeholder div), `features/Draw/Shapes/Shape.tsx` (рабочий маппинг type→Konva), `entities/shapes/` (типы ShapeConfig, определения шейпов). Эта спека заменяет все заглушки реальной реализацией.

## 1. User Flow

### 1.1 Открытие редактора

```
Пользователь на странице мнемосхем → кликает карточку или ✏️
  → Навигация на /objects/:objectId/diagrams/:diagramId/edit
  → Загружается EditorPage (editor mode layout)
  → Параллельно:
    GET /diagrams/:diagramId         → метаданные диаграммы (name, published_at)
    GET /diagrams/:diagramId/figures → список фигур
  → Canvas рендерит фигуры
  → Viewport автоматически подстраивается под фрейм (fit-to-frame)
  → Если фигур нет → пустой фрейм с подсказкой «Добавьте фигуру из палитры слева»
```

### 1.2 Навигация по холсту

```
Бесконечный холст Konva:
  Ctrl + Scroll          → Zoom (по курсору, диапазон 10%–500%)
  Scroll                 → Вертикальный pan
  Shift + Scroll         → Горизонтальный pan
  Middle mouse drag      → Pan (свободный)
  Space + Left drag      → Pan (свободный)
  Trackpad pinch         → Zoom

Двойной клик на пустом месте → Fit-to-frame (сбросить viewport на фрейм)
```

### 1.3 Фрейм экрана

```
Пользователь выбирает разрешение фрейма из селектора в Footer:
  → Доступные пресеты:
    Full HD   1920 × 1080  (по умолчанию)
    QHD       2560 × 1440
    4K UHD    3840 × 2160
    HD        1280 × 720
    XGA       1024 × 768
  → Фрейм рендерится как прямоугольник на холсте:
    - Позиция: начало координат (0, 0)
    - Внутри: белый фон (#FFFFFF)
    - Снаружи: серый фон холста (#F5F5F5)
    - Граница: 1px dashed #DEE2E6
    - Лейбл сверху: «1920 × 1080» мелким текстом
  → Фигуры можно размещать и за пределами фрейма
  → Настройка фрейма сохраняется в localStorage: editor:frame:{diagramId}
```

### 1.4 Добавление фигуры

```
Пользователь кликает иконку в палитре (напр. Rectangle)
  → Активный инструмент меняется на «rect»
  → Курсор на холсте: crosshair
  → Клик на холсте → фигура создаётся в точке клика с размерами по умолчанию
  → POST /diagrams/:diagramId/figures { type: "rect", params: { x, y, width: 120, height: 80, fill: "#228BE6", ... } }
  → Фигура сразу выделяется, Properties panel показывает свойства
  → Инструмент сбрасывается на «select»
```

MVP-фигуры для палитры: `rect`, `circle`, `line`, `text`, `image`.
Расширенные (уже в типах, но без иконок в палитре): `ellipse`, `wedge`, `ring`, `arc`, `tag`, `path`.

### 1.5 Выделение и редактирование

```
Инструмент «select» (по умолчанию):
  → Клик на фигуру → выделяет её
    → Konva Transformer показывает handles (resize по углам, rotate сверху)
    → Properties panel показывает свойства
  → Клик на пустое место → снятие выделения
  → Drag выделенной фигуры → перемещение
    → По окончании drag → PATCH /figures/:id { params: { ...updated x, y } }
  → Resize через Transformer handles
    → По окончании → PATCH /figures/:id { params: { ...updated width, height } }
  → Delete key → удаление выделенной фигуры
    → DELETE /figures/:id
    → Фигура исчезает с холста и из списка слоёв
```

### 1.6 Привязка тега

```
Фигура выделена → Properties panel → вкладка «Привязка данных»
  → Select с поиском тегов (GET /tags?search=...)
  → Пользователь выбирает тег из списка
  → PATCH /figures/:id { tag_id: "uuid-тега" }
  → В панели отображается: имя тега, device_id
  → Кнопка «Отвязать» → PATCH /figures/:id { tag_id: null }
```

### 1.7 Управление слоями

```
Левая панель → секция «Слои» (нижняя часть Panel):
  → Список фигур в порядке z-index (сверху вниз = спереди → сзади)
  → Клик по элементу списка → выделяет фигуру на холсте
  → Иконка глаза → скрыть/показать фигуру (visible: false в params)
  → Drag & drop для изменения z-order (перерисовка порядка в Konva Layer)
```

### 1.8 Сохранение

```
Каждое изменение фигуры сохраняется через API:
  - Создание → POST (мгновенно)
  - Удаление → DELETE (мгновенно)
  - Редактирование свойств → PATCH (debounce 500ms после последнего изменения)
  - Drag/resize → PATCH (на mouseUp / transformEnd)

Footer показывает статус:
  «Сохранено»       → зелёная точка
  «Сохранение...»   → анимированная точка
  «Ошибка сохранения» → красная точка (с retry по клику)
```

### 1.9 Публикация

```
Пользователь нажимает «Опубликовать» в Toolbar
  → Modal подтверждения: «Опубликовать мнемосхему?»
  → POST /diagrams/:diagramId/publish
  → Статус в header обновляется: «Опубликована»
```

### 1.10 Выход из редактора

```
Пользователь нажимает ← (Back) в Toolbar
  → Навигация на /objects/:objectId/diagrams
```

```ts
import { create } from "zustand";
import type { EditorTool, FramePreset, SaveStatus } from "./types";
import { FRAME_PRESETS } from "./types";

interface EditorState {
  // Canvas viewport
  zoom: number;               // 0.1 – 5.0
  panX: number;
  panY: number;

  // Tool
  activeTool: EditorTool;

  // Selection
  selectedFigureIds: string[];

  // Frame
  frame: FramePreset;

  // Save status
  saveStatus: SaveStatus;

  // Actions
  setZoom: (zoom: number) => void;
  setPan: (x: number, y: number) => void;
  setActiveTool: (tool: EditorTool) => void;
  selectFigure: (id: string) => void;
  clearSelection: () => void;
  setFrame: (preset: FramePreset) => void;
  setSaveStatus: (status: SaveStatus) => void;
  reset: () => void;
}

export const useEditorStore = create<EditorState>((set) => ({
  zoom: 1,
  panX: 0,
  panY: 0,
  activeTool: "select",
  selectedFigureIds: [],
  frame: FRAME_PRESETS[0], // Full HD
  saveStatus: "saved",

  setZoom: (zoom) => set({ zoom: Math.min(5, Math.max(0.1, zoom)) }),
  setPan: (panX, panY) => set({ panX, panY }),
  setActiveTool: (activeTool) => set({ activeTool }),
  selectFigure: (id) => set({ selectedFigureIds: [id] }),
  clearSelection: () => set({ selectedFigureIds: [] }),
  setFrame: (frame) => set({ frame }),
  setSaveStatus: (saveStatus) => set({ saveStatus }),
  reset: () => set({
    zoom: 1, panX: 0, panY: 0,
    activeTool: "select",
    selectedFigureIds: [],
    saveStatus: "saved",
  }),
}));
```

### 7.2 EditorCanvas

Центральный компонент — Konva `Stage` с тремя слоями.

**Размер Stage**: автоматически подстраивается под размер контейнера (`ResizeObserver` или `useElementSize` из `@mantine/hooks`).

**Обработка `onWheel`**:
```ts
function handleWheel(event: KonvaEventObject<WheelEvent>) {
  event.evt.preventDefault();
  if (event.evt.ctrlKey || event.evt.metaKey) {
    // Zoom at cursor position
    zoomAtPoint(stage, event.evt.deltaY, pointerPos);
  } else if (event.evt.shiftKey) {
    // Horizontal pan
    setPan(panX - event.evt.deltaY, panY);
  } else {
    // Vertical pan
    setPan(panX, panY - event.evt.deltaY);
  }
}
```

**Обработка клика для создания фигуры**:
```ts
function handleMouseDown(event: KonvaEventObject<MouseEvent>) {
  if (activeTool === "select") {
    // Клик по пустому месту → снять выделение
    if (event.target === event.target.getStage()) {
      clearSelection();
    }
    return;
  }

  // Инструмент шейпа: создать фигуру в точке клика
  const pos = stage.getRelativePointerPosition(); // canvas coords
  const params = { ...DEFAULT_FIGURE_PARAMS[activeTool], x: pos.x, y: pos.y };
  addFigure(diagramId, { type: activeTool, params });
  setActiveTool("select"); // Сбросить на select
}
```

## Constraints

- **Фасадный паттерн**: NumberInput, ColorInput, Slider, Popover через `shared/ui/components/`. Ни один файл за пределами `shared/ui/components/` не импортирует `@mantine/core` напрямую.
- **FSD**: EditorCanvas, FigureRenderer, FrameGuide — `features/editor/ui/`. ShapePalette, LayerList, PropertiesPanel — `widgets/`. Figure entity — `entities/figures/`.
- **Konva**: Используем `konva` + `react-konva` (уже в зависимостях). Не добавлять новых canvas-библиотек.
- **Иконки**: `@tabler/icons-react` (уже в зависимостях Mantine).
- **Не реализовывать в этой спеке**: undo/redo, copy/paste, alignment/distribution, snap to grid, группировка, multi-select (marquee), keyboard shortcuts кроме Delete, auto-save, image upload dialog, path drawing tool.
- **Frame persistence**: localStorage `editor:frame:{diagramId}`. Бэкенд-хранение фрейма — будущая задача.
- **API debounce**: Изменения свойств в PropertiesPanel отправляются через debounce 500ms. Drag/resize — на mouseUp.
