#+ Инженер: создать мнемосхему

Как инженер, я хочу создать мнемосхему объекта и подготовить её к публикации, чтобы операторы могли видеть актуальное состояние.

Предусловия
- Объект создан (`public.objects`).
- Есть теги для привязки (см. сценарий «Инженер: добавить устройство»).

Поток
1) Создать схему: POST `/objects/{id}/diagrams` (ms-editor API).
2) Добавить фигуры: POST `/diagrams/{id}/figures` (геometrия/типы).
3) Сохранить параметры фигур: `public.figure_params` (JSONB — визуальные правила/скрипты, если поддерживается).
4) Предпросмотр и публикация: POST `/diagrams/{id}/publish`.

Acceptance Criteria
- Схема сохраняется как черновик; после публикации доступна в Viewer.
- Фигуры корректно отображаются; недостающие теги отмечаются.

Связанные сущности и API
- Таблицы: `public.mimic`, `public.figures`, `public.figure_params`.
- API: `04_API/ms-editor.md`.
