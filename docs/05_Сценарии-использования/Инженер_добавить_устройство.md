#+ Инженер: добавить устройство (Modbus/SNMP)

Как инженер АСУ/интегратор, я хочу добавить устройство и настроить опрос, чтобы получать значения параметров в системе.

Предусловия
- Доступ по роли инженер/интегратор.
- В `ms-editor` доступны справочники `device_type`, `data_types`, `units`.

Поток
1) Создать устройство: POST `/devices` (name, type).
2) Задать конфигурацию: POST `/devices/{id}/config` (settings JSONB для Modbus TCP/RTU или SNMP).
3) Добавить теги: POST `/devices/{id}/tags` (name, tag_params: address, data_type_id, unit_id, scale?).
4) Проверить опрос: дождаться публикации из `ms-poll` (по UI-индикатору или логам), увидеть последние значения в Viewer.

Acceptance Criteria
- Устройство отображается в списке, конфиг валидируется по протоколу.
- Теги видны и получают значения (обновление «последних значений» через Redis/`ms-viewer`).
- Ошибки протокола отражаются (quality=bad/uncertain), есть диагностические логи.

Связанные сущности и API
- Таблицы: `devices.devices`, `devices.devices_params`, `tags.tags`, `tags.tag_params`.
- API: `04_API/ms-editor.md`.
