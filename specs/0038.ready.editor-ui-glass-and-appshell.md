# 0038: editor-ui — Glass-примитивы + AppShell в двух режимах + ambient orbs

## Scope

`editor-ui/src/`:

1. CSS-классы glass-примитивов: `.glass`, `.glass-strong`, `.glass-soft`, `.glass-flat` + `::before`-highlight.
2. Pastel-orbs ambient background — фиксированный backdrop под всем приложением.
3. Перевод всех 6 слотов `shared/ui/Layout/` (Layout, Header, Navbar, Panel, Aside, Footer) на токены из 0037 + glass-классы.
4. Two-mode AppShell: `mode="list"` и `mode="editor"`. Navbar и Panel взаимоисключающие.
5. Collapse-логика: Navbar, Panel, Aside.

Out of scope: реcтайл компонентов (Button/Input/Tabs/Modal — это 0039); editor canvas — 0040; экраны — 0041.

Зависимости: 0037.

## Context

- Хэндофф [README.md](../design_handoff_editor_ui/README.md) § «Layout — AppShell» — слоты, размеры, режимы.

## Interface

### Glass classes (`glass.module.css`)

```css
.glass {
  position: relative;
  background: var(--glass-bg);
  backdrop-filter: var(--glass-blur);
  -webkit-backdrop-filter: var(--glass-blur);
  border: 1px solid var(--glass-border);
  border-radius: 14px;
  box-shadow: var(--glass-shadow);
  isolation: isolate;
}

.glass::before {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--glass-highlight);
  border-radius: inherit;
  pointer-events: none;
  z-index: 1;
}

.glass > * {
  position: relative;
  z-index: 2;
}

.glassStrong { background: var(--glass-bg-strong); }
.glassSoft   { background: var(--glass-bg-soft); }
.glassFlat   { border-radius: 4px; }
```

Fallback для браузеров без `backdrop-filter`:

```css
@supports not (backdrop-filter: blur(20px)) {
  .glass { background: var(--bg-surface); }
}
```

И reduced-transparency:

```css
@media (prefers-reduced-transparency: reduce) {
  .glass {
    background: var(--bg-surface);
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
  }
  .glass::before { display: none; }
}
```

### AmbientOrbs

Фон — `position: fixed; inset: 0; z-index: -1; pointer-events: none; overflow: hidden;`. Внутри 4 orb-кругов:

```jsx
<div className={styles.root} aria-hidden>
  <span className={styles.orb} style={{ "--orb": "var(--orb-1)", left: "10%",  top: "10%" }} />
  <span className={styles.orb} style={{ "--orb": "var(--orb-2)", right:"15%", top: "20%" }} />
  <span className={styles.orb} style={{ "--orb": "var(--orb-3)", left: "20%", bottom: "10%" }} />
  <span className={styles.orb} style={{ "--orb": "var(--orb-4)", right:"10%", bottom: "15%" }} />
</div>
```

```css
.orb {
  position: absolute;
  width: 360px; height: 360px;
  border-radius: 50%;
  background: var(--orb);
  filter: blur(80px);
  opacity: 0.45;
}
[data-theme="dark"] .orb { opacity: 0.35; }

@media (prefers-reduced-motion: reduce) { .orb { animation: none; } }
```

Animation — статика. Лёгкое медленное «дыхание» (60s loop, scale 1.0 ↔ 1.05) — добавить опционально под флагом `<AmbientOrbs animated />`; default — статика (производительность).

### `<Layout>` API

```tsx
<Layout
  mode="list" | "editor"
  navbarCollapsed?: boolean
  panelCollapsed?: boolean
  asideCollapsed?: boolean
  onToggleNavbar?: () => void
  onToggleAside?: () => void
>
  <Layout.Header>{...}</Layout.Header>
  <Layout.Navbar>{...}</Layout.Navbar>      {/* только list-mode */}
  <Layout.Panel>{...}</Layout.Panel>        {/* только editor-mode */}
  <Layout.Main>{...}</Layout.Main>
  <Layout.Aside>{...}</Layout.Aside>
  <Layout.Footer>{...}</Layout.Footer>
</Layout>
```

В `mode="list"`:
- `Header` height 56px (mobile) / 64px (≥md), glass.
- `Navbar` width 240px (mobile) / 280px (≥md), glass, collapsible.
- `Aside` — рендерится только если потомок `<Layout.Aside>` явно передан.
- `Panel` отбрасывается с warn-логом.
- `Footer` — рендерится только если передан.

В `mode="editor"`:
- `Header` — те же размеры.
- `Panel` width 240/280, glass.
- `Aside` width 280/320, glass, collapsible.
- `Navbar` отбрасывается с warn-логом.
- `Footer` height 48/56, glass.

При collapse слот → width: 0, контент перетекает. Анимация `transition: width 200ms ease`.

Под капотом — Mantine `AppShell` (он же `<AppShell>`); slots — `<AppShell.Header>`, `<AppShell.Navbar>`, etc. `<Layout>` — обёртка, которая выбирает нужные slots.

### Mantine theme overrides для AppShell-слотов

В `editor-ui/src/shared/libs/theme/theme.ts` (расширение из 0037):

```ts
components: {
  AppShellHeader: { defaultProps: { className: "glass glass-flat" } },
  AppShellNavbar: { defaultProps: { className: "glass" } },
  AppShellAside:  { defaultProps: { className: "glass" } },
  AppShellFooter: { defaultProps: { className: "glass" } },
}
```

Альтернатива — обёртка-классы передаются прямо из `<Layout.Header>` etc. Default — через theme.components (меньше правок в самих компонентах).

## Constraints

- Glass применяется **только** на chrome-слотах. Содержимое `<Main>` (`canvas`, таблицы, drawer-формы) — flat.
- `<Modal>`, `<Popover>`, `<Menu>` (Mantine) тоже должны получить glass — это в 0039 (override `theme.components.Modal.styles`).
- В `mode="editor"` обязательно убрать `<Navbar>` из дерева (не просто скрывать `display: none`) — иначе `AppShell` ест ширину под слот.
- Collapse-анимация — только `width`, не `transform/scale` (последние ломают `backdrop-filter`).
- `AmbientOrbs` рендерится **один раз** в Layout. Не дублировать на пер-странных уровнях.
- Z-index hierarchy:
  - `AmbientOrbs`: `-1`.
  - AppShell-слоты: `auto` (default).
  - Modal/Popover/Menu (Mantine): `1000+` (стандарт).
- Mobile/low-end fallback (`prefers-reduced-transparency`) уже встроен в CSS — отдельной JS-логики не нужно.
- Не использовать `position: sticky` на slot-контейнерах — `AppShell` уже делает это правильно.
- Не ломать существующее API трёх-зонной шапки: `<Layout.Header before={...} main={...} after={...}>` или children — оба варианта оставить рабочими.
- `data-theme` атрибут берётся с `<body>` (см. 0037), а не с `:root`. CSS-селектор orbs — `[data-theme="dark"] .orb`, не `:root[data-theme="dark"]`.
- Никаких прямых `@mantine/core` импортов внутри `widgets/` или `pages/` — продолжаем фасад через `shared/ui/components`.

## Verify

- `npm run build && npm run lint` — без ошибок.
- Открыть `/objects` → Layout рендерит Header + Navbar + Main, glass виден на Header и Navbar, Aside и Footer не рендерятся.
- В DevTools → Inspect → AppShell.Header содержит class `glass glass-flat`, computed `backdrop-filter: saturate(180%) blur(20px)`.
- За `<AppShell>` виден `AmbientOrbs` (4 размытых круга в углах). При переключении на dark — orbs тоже меняют цвет.
- Открыть `/objects/.../diagrams/.../edit` → Navbar исчез, появился Panel слева (240/280px), Aside справа (280/320px), Footer снизу (48/56px). Все — с glass.
- Кнопка collapse Navbar (в list) — анимирует ширину 240→0 за 200ms; контент Main перетекает плавно.
- В Safari < 14 (или с эмуляцией `@supports not`) — glass-классы дают solid `var(--bg-surface)`, без visual-glitch.
- В системе с `prefers-reduced-transparency: reduce` — glass отключён, никаких blur-эффектов.
- Pixel-test: визуальное сравнение Header/Navbar/Panel/Aside/Footer с эталонными скринами из HTML-референса (вручную или через Playwright screenshot — на усмотрение Codex).
- Запустить страницу `/objects/.../diagrams/.../edit` с уже существующим Konva-canvas → canvas работает как раньше; glass-слоты не закрывают канвас (z-index корректен).
- DevTools Performance: рендер первой страницы ≤ 16ms на M1 (FPS 60); backdrop-filter не вызывает jank на скролле.
- На low-end машине (имитация 4× CPU throttling) — скролл главного списка устройств остаётся плавным; FPS ≥ 30.
