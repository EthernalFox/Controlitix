# Controlitix

Controlitix is a monitoring-first SCADA platform for dispatching and monitoring distributed facilities.

## Repository

This repository is a monorepo and contains:

- `docs` — product and architecture documentation
- `ms-editor` — engineering configuration backend
- `ms-poll` — device polling service
- `ms-viewer` — viewing, alarms, trends, history, notifications
- `editor-ui` — engineering frontend
- `viewer-ui` — operator frontend
