#+ Инженер: привязать фигуры к тегам

Как инженер, я хочу привязать фигуры на мнемосхеме к тегам, чтобы отображать значения в реальном времени.

Предусловия
- Создана мнемосхема и фигуры.
- Есть теги (`tags.tags`, `tags.tag_params`).

Поток
1) В редакторе выбрать фигуру и указать `tag_id` (сохранение в `public.figures.tag_id`).
2) Настроить правила отображения в `figure_params` (цвет/видимость/текст по значению/quality).
3) Проверить в Viewer, что обновления поступают (через Redis/`ms-viewer` или WS).

Acceptance Criteria
- Для каждой привязанной фигуры отображается актуальное значение и состояние качества.
- Обновления происходят без перезагрузки страницы.

Связанные сущности и API
- Таблицы: `public.figures`, `public.figure_params`, `tags.tags`.
- API: `04_API/ms-editor.md`.
