# Kafka

Назначение
- Шина событий для показаний/значений, конфигураций и аудита.

Предварительные топики (черновик)
- `ms-poll` — нормализованные текущие значения от `ms-poll` (tag_id, value, ts, quality, meta).
- `raw.readings` — сырые показания драйверов (опционально).
- `alarms.events` — события тревог, публикуемые `ms-viewer` (срабатывание, восстановление, квитирование).
- `config.changed` — изменения конфигураций (объекты/устройства/теги/схемы).
- `audit.logs` — действия пользователей/сервисов (опционально).

Политики
- Ретеншн и DLQ (dead-letter) для обработчиков.
- Ключи сообщений: рекомендуем по `tag_id`/`device_id` для локальности партиций.
- Схемы сообщений: фиксировать в отдельной спецификации (JSON/Avro, TBA).
