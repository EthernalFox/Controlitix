# viewer-ui — фронтенд просмотрщика

Назначение
- Просмотр опубликованных мнемосхем, значений в реальном времени, тревог и трендов.

Стек
- React 19.2+
- TypeScript 5
- Zustand
- PixiJS (производительный рендер схем)
- Mantine UI 8
- ChartJS (тренды)

Интеграции
- WebSocket/Realtime через `ms-viewer` (подписки на изменения по объектам/тегам).
- REST к `ms-viewer` для загрузки трендов, архивов и операций с тревогами.

НФТ
- Деградация до polling, буферизация/дребезг обновлений.
