# 0001: editor-ui — Layout и Design System

## Scope

`editor-ui` — полностью. Затрагивает `shared/ui/Layout`, виджеты (`widgets/`), страницы (`pages/`), дизайн-токены.

## Context

Фиксирует архитектурные решения по лейауту и визуальной системе editor-ui перед началом реализации экранов. Решения приняты совместно с владельцем продукта.

Связанные документы:
- `docs/06_Дизайн/Design-System.md` — цветовая палитра, типографика, spacing.
- `docs/06_Дизайн/Information-Architecture.md` — sitemap, навигационная модель.
- `docs/06_Дизайн/Figure-Types.md` — набор типов фигур.
- `docs/02_Архитектура/Микросервисы/editor-ui.md` — функции и НФ-требования.

## 1. UI Kit — решение

**Mantine 8** — финальный выбор. Миграция на shadcn/ui отклонена.

Обоснование:
- Mantine уже установлен (`@mantine/core: ^8.2.1`) и используется (AppShell, формы).
- Встроенный AppShell с header/navbar/aside/footer — основа лейаута.
- Двойная тема (dark/light) из коробки через CSS-переменные.
- Компактные размеры (`size="xs"/"sm"`) критичны для SCADA-плотности.
- Модалки, drawer, notifications, select, tabs — всё есть.
- shadcn потребовал бы: установку Tailwind, полную переписку Layout, ручную сборку каждого компонента — без выигрыша для инженерного UI.

## 2. Лейаут — общая модель

### 2.1 Два режима лейаута

editor-ui имеет два принципиально разных режима:

```
┌─────────────────────────────────────────────────┐
│  LIST MODE (objects, devices, tags, diagrams)   │
├─────────────────────────────────────────────────┤
│  Header: logo | page title           | user     │
│─────────────────────────────────────────────────│
│  Navbar    │         Content                    │
│  (nav      │         (table / cards / form)     │
│   tree)    │                                    │
│            │                                    │
│            │                                    │
│            │                                    │
└─────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────┐
│  EDITOR MODE (diagram edit)                     │
├─────────────────────────────────────────────────┤
│  Header: logo | toolbar(Align,Grid…) | Publish  │
│─────────────────────────────────────────────────│
│  Panel     │         Canvas          │  Aside   │
│  (figures  │         (Konva Stage)   │  (tabs:  │
│   palette  │                         │  Props,  │
│   + layers)│                         │  Data)   │
│            │                         │          │
│─────────────────────────────────────────────────│
│  Footer: Undo Redo | Zoom | Snap | status       │
└─────────────────────────────────────────────────┘
```

### 2.2 Взаимоисключение left panel

- **List mode** — используется слот `navbar`: навигационное дерево объектов.
- **Editor mode** — используется слот `panel`: палитра фигур и список слоёв. Слот `navbar` скрыт.

Они **никогда не показываются одновременно**. Выбор между объектами/схемами происходит на экране списков ДО входа в редактор.

### 2.3 Footer — только в редакторе

- На страницах списков footer **отсутствует**.
- В редакторе footer — полноценный toolbar.

### 2.4 Сворачивание панелей

- Left panel (navbar или panel) и right panel (aside) **сворачиваются по кнопке**.
- Кнопка расположена в углу панели (chevron-иконка).
- При сворачивании панель уходит в 0px ширины, холст/контент занимает освободившееся пространство.
- Хоткей — опционально (not MVP-blocking, можно добавить позже).

## 3. Header

### 3.1 Структура (3 зоны)

```
┌──────────┬────────────────────────┬─────────────┐
│  before  │         main           │    after     │
└──────────┴────────────────────────┴─────────────┘
```

### 3.2 List mode

| Зона | Содержимое |
|------|-----------|
| `before` | Logo (компонент `<Logo />`) |
| `main` | Заголовок страницы (текст: «Объекты», «Устройства», «Теги», «Мнемосхемы») |
| `after` | Иконка пользователя (avatar/dropdown с logout) |

### 3.3 Editor mode

| Зона | Содержимое |
|------|-----------|
| `before` | Logo + кнопка «Назад к списку схем» |
| `main` | Toolbar: Align, Distribute, Grid, Snap to Grid |
| `after` | Preview, Publish, иконка пользователя |

### 3.4 Размеры

- Height: `56px` (base), `64px` (sm+).
- Padding: 0 16px.

## 4. Left Panel — Navbar (list mode)

### 4.1 Назначение

Навигационное дерево объектов мониторинга. Инженер выбирает объект, затем переключается между вкладками (Устройства, Теги, Мнемосхемы) в контентной области.

### 4.2 Содержимое

- Заголовок «Объекты» + поиск (TextInput).
- Список объектов (карточки или строки).
- Кнопка «Создать объект» внизу.
- Кнопка сворачивания (chevron) в верхнем правом углу панели.

### 4.3 Размеры

- Width: `240px` (base), `280px` (md+).
- Collapsible → 0px.

---

## 5. Left Panel — Panel (editor mode)

### 5.1 Назначение

Палитра фигур для добавления на холст + список слоёв/элементов текущей схемы.

### 5.2 Содержимое

Две секции (не tabs — вертикальный split):

**Верхняя секция — Figures palette:**
- Сетка иконок фигур: rect, circle, ellipse, line, text, image, wedge, ring, arc, tag, path.
- Drag-to-canvas или click-to-add.
- Группировка: «Basic» (rect, circle, line, text, image) и «Extended» (остальные).

**Нижняя секция — Layers / Elements:**
- Список всех элементов текущей схемы.
- Поиск.
- Порядок = Z-order (drag для переупорядочивания).
- Иконка видимости (eye toggle) для каждого элемента.
- Выбор элемента в списке → выделение на холсте (и наоборот).

### 5.3 Размеры

- Width: `240px` (base), `280px` (md+).
- Collapsible → 0px.
- Кнопка сворачивания — chevron в верхнем правом углу.

---

## 6. Right Panel — Aside (editor mode only)

### 6.1 Назначение

Свойства выбранной фигуры и привязка к тегам.

### 6.2 Вкладки (Mantine Tabs)

Две вкладки:

**Tab 1: Properties (Свойства)**

Показывается всегда. Если фигура не выбрана — placeholder «Выберите элемент».

Секции при выбранной фигуре:
- **Position**: X, Y (числовые инпуты).
- **Size**: W, H (числовые инпуты). Для line/path — точки.
- **Rotation**: угол (числовой инпут).
- **Appearance**: Fill (color picker), Stroke (color + width), Opacity (slider).
- **Text** (только для type=text): text, fontSize, fontFamily.
- **Z-order**: кнопки Bring Forward / Send Backward / Bring to Front / Send to Back.

**Tab 2: Data Binding (Привязка данных)**

Привязка выбранной фигуры к тегу и настройка правил динамики.

Секции:
- **Tag**: Select-поле с поиском тега из справочника ms-editor. Показывает: имя тега, устройство, единицу измерения.
- **Rules**: список правил «условие → эффект»:
  - Условие: оператор (`>`, `>=`, `==`, `<`, `<=`, `!=`, `range`) + значение.
  - Эффект: смена `fill`, `stroke`, `visible`, `text`.
  - Кнопка «Add rule».
  - Для boolean-тегов: упрощённый режим `true → X, false → Y`.
- **Preview**: индикатор текущей привязки (имя тега, тип, статус).

### 6.3 Без вкладки «Устройства и теги»

Управление устройствами и тегами происходит на отдельных страницах списков (`/objects/:id/devices`, `/objects/:id/tags`) в list mode. В редакторе мнемосхемы инженер только **привязывает** уже созданные теги к фигурам через вкладку Data Binding.

### 6.4 Размеры

- Width: `280px` (base), `320px` (md+).
- Collapsible → 0px.
- Кнопка сворачивания — chevron в верхнем левом углу панели.

## 7. Footer Toolbar (editor mode only)

### 7.1 Структура

```
┌──────────────────────────────────────────────────┐
│ Undo Redo │ Zoom- [100%] Zoom+ │ ⊞ Snap │ status │
└──────────────────────────────────────────────────┘
```

### 7.2 Секции (разделены вертикальным разделителем)

| Секция | Содержимое |
|--------|-----------|
| History | Undo (⌘Z), Redo (⌘⇧Z) — иконки-кнопки, disabled когда нечего откатить |
| Zoom | Zoom Out, текущий %, Zoom In, Fit to Screen |
| Grid & Snap | Toggle: Snap to Grid (вкл/выкл), Show Grid (вкл/выкл) |
| Status (right-aligned) | Статус сохранения: «Сохранено» / «Сохранение…» / «Ошибка». Координаты курсора (X, Y) |

### 7.3 Размеры

- Height: `48px` (base), `56px` (sm+).
- Padding: 0 16px.
- Фигуры **не** в footer — они в левой панели (секция Figures palette).

## 9. Дизайн-токены

Наследуются из `docs/06_Дизайн/Design-System.md`. Ключевые решения для реализации:

### 9.1 Тема

- **Light theme — основная для editor-ui** (инженер работает при нормальном освещении).
- **Dark theme — обязательна** (переключатель в user menu).
- Реализация: Mantine `MantineProvider` с `colorScheme`, CSS-переменные.

### 9.2 Токены панелей

| Токен | Light | Dark |
|-------|-------|------|
| `panel-bg` | `#FFFFFF` | `#1A1D2E` |
| `panel-border` | `#E0E0E0` | `#3A3F5C` |
| `canvas-bg` | `#F5F5F5` | `#111422` |
| `toolbar-bg` | `#FAFAFA` | `#232740` |

### 9.3 Типографика

- Основной: Inter (400, 500, 600).
- Моноширинный (значения тегов в Data Binding): JetBrains Mono.
- Базовый размер панелей: 12–13px.
- Заголовки секций в панелях: 13px / 600.

### 9.4 Spacing

- Базовая сетка: 8px.
- Padding внутри панелей: 12px.
- Межсекционный gap: 16px.
- Gap между элементами внутри секции: 8px.
